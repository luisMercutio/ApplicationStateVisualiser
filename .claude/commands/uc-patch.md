Renamed to `/epic-patch` (Epic/BR methodology). Apply a small targeted patch to a Done Epic.

This command was renamed. **Use `/epic-patch` instead** — it does exactly what
`/uc-patch` used to do, in the Epic/BR methodology. Read `.claude/commands/epic-patch.md`
and follow it with the same `$ARGUMENTS`.

If the change is purely one new Business Rule that fits an existing Epic (no new
entity/table/endpoint-group/slice/route), use `/br-add $ARGUMENTS` instead.
